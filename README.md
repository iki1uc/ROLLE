# ROLLE · GEO-Modular

SEED ⟁ bildet den Ursprung.

Die sechs Rollen sind geometrisch angeordnet:

- ORT  → Position
- HOME → Zentrum
- USER → Zugriff
- USE  → Funktion
- OUT  → Ausgabe
- ROLLE → Gesamtform

Zusammen ergeben sie einen modularen Aufbau,
sichtbar als sechsfache GEO-Struktur um den SEED.
        ORT
   USER     USE

       ⟁ (HOME)

   OUT      ROLLE
